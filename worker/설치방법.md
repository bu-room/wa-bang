# 와방 매물 보호 (문지기) 설치 방법

손님 사이트 ──▶ 문지기(Cloudflare Worker) ──▶ 매물등록 Apps Script ──▶ 구글 시트

순서대로 하세요. 5번(웹에 게시 중지)은 사이트가 새 방식으로 매물을 잘 보여주는 걸 확인한 **뒤에** 합니다.

## 1. 매물등록 Apps Script 업데이트
1. script.google.com → 매물등록 프로젝트 → `apps-script/매물등록.gs` 전체 붙여넣기 (**SHEET_ID 줄은 기존 값 유지**)
2. 함수 선택 '설치하기' → 실행 → 권한 허용 (메일 보내기 권한이 새로 추가돼요)
3. 실행 로그의 `🔑 문지기 열쇠(WORKER_KEY): …` 값을 복사해 둠
4. 배포 → **배포 관리** → 연필 → 버전 '새 버전' → 배포 (주소 그대로 유지)

## 2. Turnstile(사람 확인) 만들기
1. Cloudflare → Turnstile → 위젯 추가
2. 호스트 이름: `skylee-lang.github.io`, `bu-room.github.io`
3. 위젯 모드: **관리형(Managed)**
4. 나온 **사이트 키**(공개용)와 **비밀 키**(비밀)를 복사

## 3. 문지기 Worker 만들기
1. Cloudflare → Workers 및 Pages → 만들기 → Worker → 'Hello World'로 시작 → 이름 예: `wabang-gate` → 배포
2. 코드 편집 → `worker/worker.js` 전체 붙여넣기 → 배포
3. 설정 → 변수 및 비밀 → 아래 5개를 **비밀(Secret)** 로 추가
   | 이름 | 값 |
   |---|---|
   | GAS_URL | 매물등록 Apps Script 웹앱 주소 (…/exec) |
   | GAS_KEY | 1-3에서 복사한 WORKER_KEY |
   | TURNSTILE_SECRET | 2-4의 비밀 키 |
   | SESSION_SECRET | 아무 무작위 글자 40자 이상 |
   | ALLOWED_ORIGINS | `https://skylee-lang.github.io,https://bu-room.github.io` |
4. Worker 주소(`https://wabang-gate.….workers.dev`) 복사 → 브라우저로 열어서 `ok` 가 나오면 성공

## 4. 사이트 설정
- `index.html` CONFIG: `API_URL` = Worker 주소, `TURNSTILE_SITEKEY` = 2-4의 사이트 키
- `chat/index.html` CONFIG: `API_URL` = Worker 주소
- 둘 다 비어 있으면 사이트에 **샘플 매물**이 보여요 (설정 전 상태)

## 5. 확인 후 시트 '웹에 게시' 중지 (가장 중요)
1. 휴대폰(인스타·카톡 앱 안)에서 사이트 열기 → 매물 목록·상세 사진이 다 보이는지 확인
2. 구글 시트 → 파일 → 공유 → 웹에 게시 → **게시 중지**
3. 예전 CSV 주소를 브라우저에서 열어서 안 열리는지 확인

## 이후 바뀌는 점
- 매물 등록 후 사이트 반영: 최대 5분 → **약 1분**
- 사이트에는 **진행중(상태 빈칸 포함) 매물만** 보임. 거래완료·숨김은 아예 안 나감
- 거래완료·숨김 매물 사진은 링크 공개가 꺼짐 (상태를 바꿀 때 바로 + 매일 새벽 5시)
- 이상한 대량 조회는 1시간 차단되고 내 메일로 알림

## 점검
- Worker 화면 → 로그(관측성)에서 오류 확인
- 열쇠를 바꾸고 싶으면: Apps Script '문지기열쇠_바꾸기' 실행 → Worker 의 GAS_KEY 도 같은 값으로
